EEGFlow› Dataset Guidelines

Dataset Formatting Guidelines

EEGFlow accepts CSV files that follow a specific column structure. This page explains how to convert any EEG dataset into a compatible format.

📄
File Format

Plain .csv with comma-separated values and a header row

🏷️
Column Naming

Use standard keywords for time, subject, event and electrode names

🔢
Data Type

All EEG channel values must be numeric (float/int). String columns are excluded automatically

✅
Missing Values

NaNs are allowed — EEGFlow will interpolate them automatically per subject

01

Required CSV Structure

Your CSV file must include at least one numeric EEG channel column. All other columns are optional but recommended.

Column Role Accepted Column Names (examples) Required? Description
Time time, timestamp, time_ms, time_sec Recommended Timestamps per sample. Used to auto-detect sampling rate (fₛ). Can be in milliseconds or seconds.
Subject subject_id, subject, participant, participant_id Optional Participant identifier. When present, NaN interpolation is performed per-subject to prevent data leakage.
Event / Label event, label, state, marker, class Optional Cognitive state or trial marker (e.g. Relaxed, Task). Used for epoch-level classification in later phases.
EEG Channels Fp1, Fp2, F3, C3, O1 … any electrode name Required All remaining numeric columns are treated as EEG electrode signals. Must contain float values in µV.
Excluded Metadata age, trial, trial_id, session, session_id, fs Auto-excluded These numeric metadata columns are automatically detected and excluded from EEG channel classification.

03

Converting from Common EEG Formats

Use the Python snippets below to convert your existing dataset into the EEGFlow-compatible CSV format.

🐍 convert_edf.py — Requires: mne 
import mne
import pandas as pd

# Load the EDF/BDF file
raw = mne.io.read_raw_edf("your_file.edf", preload=True)

# Extract signal data as a DataFrame
data, times = raw[:]
channel_names = raw.ch_names

df = pd.DataFrame(data.T * 1e6, columns=channel_names)  # Convert V → µV
df.insert(0, "time_ms", times * 1000)                   # Seconds → milliseconds

# Optional: add subject_id and event columns if you have annotation data
df.insert(1, "subject_id", 1)
df.insert(2, "event", "Relaxed")

df.to_csv("output_eegflow.csv", index=False)
print("Saved:", df.shape)
🐍 convert_mat.py — Requires: scipy 
import scipy.io
import pandas as pd
import numpy as np

# Load .mat file
mat = scipy.io.loadmat("your_file.mat")

# Replace 'eeg_data' and 'fs' with your actual variable names
eeg_data = mat["eeg_data"]   # Shape: (n_channels, n_samples)
fs       = int(mat["fs"])    # Sampling rate in Hz

channel_names = ["Fp1","Fp2","F3","F4","C3","C4","O1","O2"]  # Adjust to your channels

n_samples = eeg_data.shape[1]
time_ms   = np.arange(n_samples) / fs * 1000

df = pd.DataFrame(eeg_data.T, columns=channel_names)
df.insert(0, "time_ms",    time_ms)
df.insert(1, "subject_id", 1)
df.insert(2, "event",      "Relaxed")

df.to_csv("output_eegflow.csv", index=False)
print("Saved:", df.shape)
🐍 convert_openbci.py — Standard OpenBCI CSV 
import pandas as pd

# OpenBCI CSVs typically start with comment lines beginning with '%'
df_raw = pd.read_csv("your_openbci_file.csv", comment="%")
df_raw.columns = df_raw.columns.str.strip()  # Remove leading/trailing spaces

# OpenBCI channel columns are usually named 'EXG Channel 0', 'EXG Channel 1' etc.
eeg_cols = [c for c in df_raw.columns if "EXG" in c or "Channel" in c]

# Rename to standard electrode names
rename_map = {old: new for old, new in zip(eeg_cols, ["Fp1","Fp2","F3","F4","C3","C4","O1","O2"])}
df_raw.rename(columns=rename_map, inplace=True)

# Use sample index to compute time_ms (OpenBCI default: 250 Hz)
fs = 250
df_raw.insert(0, "time_ms", (df_raw.index / fs) * 1000)
df_raw.insert(1, "subject_id", 1)
df_raw.insert(2, "event", "Relaxed")

df_out = df_raw[["time_ms", "subject_id", "event"] + list(rename_map.values())]
df_out.to_csv("output_eegflow.csv", index=False)
print("Saved:", df_out.shape)
🐍 convert_generic.py — For any existing CSV 
import pandas as pd

df = pd.read_csv("your_existing_file.csv")
print("Current columns:", df.columns.tolist())

# ── Step 1: Rename your time column to one EEGFlow recognises ──
df.rename(columns={"YOUR_TIME_COL": "time_ms"}, inplace=True)

# ── Step 2: Rename subject and event columns (optional) ──
df.rename(columns={
    "YOUR_SUBJECT_COL": "subject_id",
    "YOUR_EVENT_COL":   "event",
}, inplace=True)

# ── Step 3: Rename electrode columns to standard 10-20 names ──
df.rename(columns={
    "ch1": "Fp1", "ch2": "Fp2",
    "ch3": "F3",  "ch4": "F4",
    "ch5": "C3",  "ch6": "C4",
    "ch7": "O1",  "ch8": "O2",
}, inplace=True)

# ── Step 4: Drop any columns you don't need ──
keep = ["time_ms", "subject_id", "event", "Fp1","Fp2","F3","F4","C3","C4","O1","O2"]
df = df[[c for c in keep if c in df.columns]]

df.to_csv("output_eegflow.csv", index=False)
print("Ready! Shape:", df.shape)
04

Common Mistakes & Fixes

Avoid these issues to ensure your dataset loads without errors.

❌
No numeric channel columns detected

All channel columns are strings or the column names match an excluded metadata keyword. Rename electrode columns to standard 10-20 system names (e.g. Fp1, C3).

⚠️
Sampling rate detected as 0 Hz

This happens when the time column has constant values or duplicate timestamps. Ensure time_ms strictly increases with each row.

❌
File is empty after loading

The CSV has only a header row with no data. Make sure your file contains at least 2 sample rows.

⚠️
Columns like age or session treated as EEG

These are automatically excluded by EEGFlow. If your electrode has an unusual name that conflicts, rename it to a standard 10-20 label first.
